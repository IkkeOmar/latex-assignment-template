# LaTeX assignment template

Modular LaTeX template for worked problem-set assignments. One file per question.

## Build

```bash
make
```

Compiles with [tectonic](https://tectonic-typesetting.github.io/) to `main.pdf`.
First run downloads the TeX bundle (~100 MB).

## Layout

```
main.tex        connector: class, title, TOC, part headings, \input list
preamble.tex    packages, colours, boxes, macros
q1.tex          one file per question
q2.tex
fig/            vector figures + the scripts that generate them
Makefile        make / make clean
MAP.md          which file to edit when, and the full macro list
```

## Adding a question

1. Copy an existing `qN.tex` to `q(N+1).tex` and edit it.
2. Add `\input{qN}` to `main.tex`.
3. `make`.

## Macros

| Macro | Use |
|---|---|
| `\question{n}{short title}{verbatim text}` | Numbered question. Blue box, automatic TOC entry. |
| `\partheading{A}{title}{Questions 1--10}` | Starts a new part. Forces a page break, writes a TOC entry. |
| `\Intro{text}` | Muted italic lead paragraph under a part heading. |
| `answerbox` | Environment. Purple box, for the final result. |
| `questionbox` | Environment. Blue box. Already used by `\question`. |
| `parambox` | Environment. Grey box, for given values. |
| `\dt` | Renders `delta t`. |
| `\mean{x}` | Renders `<x>`. |

## Figures

Vector PDFs generated by the scripts in `fig/`:

```bash
python fig/make_example_fig.py
```

```latex
\begin{figure}[H]
  \centering
  \includegraphics[width=0.9\textwidth]{fig/example.pdf}
  \caption{What the figure shows.}
  \label{fig:example}
\end{figure}
```

`[H]` pins the figure in place so it stays with the text discussing it.
